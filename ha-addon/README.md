# Home Assistant Add-on — Panya Charge OSS

Home Assistant add-on for [panya-charge-oss](https://github.com/chiabcc/panya-charge-oss) — an OCPP 1.6-J protocol bridge that connects EV chargers to Home Assistant via MQTT, enabling smart charging with solar surplus optimization.

## Prerequisites

- **Home Assistant MQTT** configured and accessible
- **ABB Terra AC** charger with firmware ≥ 1.8.32 (required for OCPP 1.6-J support)
